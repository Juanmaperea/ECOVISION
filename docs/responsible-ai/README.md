# IA responsable

Aspectos mínimos a documentar:

- Falsos positivos y falsos negativos.
- Sesgos del modelo de visión por iluminación, fondo, o tipo de residuo.
- Manejo de baja confianza.
- Privacidad: no almacenar imágenes en producción.
- Mensajes de advertencia al usuario cuando la recomendación requiera verificación.
